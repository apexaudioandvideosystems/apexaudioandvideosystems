APEX ADMIN DASHBOARD UPDATE

This package builds on the working website version.

UPLOAD:
- Replace the entire /admin folder with the /admin folder in this package.
- The root index.html/styles.css/assets are included as the matching master copy, but you do NOT need to replace them just to update the dashboard.

WORKING NOW:
- Admin login
- Social Media editor (Facebook, Instagram, TikTok, Google)
- Public website social icons

DASHBOARD BUTTONS INCLUDED:
- Projects
- Photos & Videos
- Services
- Reviews
- Service Areas
- Social Media
- Business Info
- Website Settings

IMPORTANT:
Only Social Media is database-connected right now. The other pages are deliberately safe placeholders. They are selectable now, but cannot accidentally overwrite the live website until we connect their Supabase tables one by one.
